# Archas Srivastava — Portfolio

A modern, single-page developer portfolio. No build step, no dependencies — just HTML, CSS, and vanilla JavaScript.

## Run locally

Open `index.html` directly, or serve the folder:

```bash
python3 -m http.server 8000
# then visit http://localhost:8000
```

## Structure

- `index.html` — markup & content
- `styles.css` — theme, layout, animations
- `script.js` — scroll reveals, typing animation, count-ups, nav
